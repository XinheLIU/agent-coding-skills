## Scope

Rewrite every model-invocable description as "Use when …" plus distinct triggers, at most about 40 words (260 bytes), and move workflow summaries into the skill body.

Measured on 2026-10-23: 43 skills, 33 model-invocable, descriptions total about 12.3 KB; 22 exceed 260 bytes. Longest are `acs-review-code-quality` (1016 bytes), `acs-refactor-code` (867), `acs-analyze-test-gaps` (842).

Add a budget check to `system/evals/validate_suite.py`: total at most 5 KB, no single description over 260 bytes, and no workflow summary in a description. Re-apply the no-op test to each model-invocable skill; flip skills the agent never needs to reach unprompted to `disable-model-invocation: true`.
