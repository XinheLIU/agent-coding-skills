# Visual Report Contract

Last updated: 2026-09-14

Use inline CSS and inline SVG as the source of truth for module design reports. Each structural module card compares current/target ownership, seam placement, dependency direction, interface depth, migration, and verification, with an adjacent takeaway and anchored top recommendation. Mermaid is optional for graph-shaped relationships; ordinary HTML labels remain readable without it. Keep diagrams roughly 320–360px tall.
