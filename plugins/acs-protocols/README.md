Shared ACS contracts and workflows; optional legacy distribution.

Generated by `scripts/build-plugins.py`; edit canonical sources, then rebuild.

Install or move this entire plugin directory. Keep `skills/` and `resources/` together; copying only `skills/` loses embedded contracts. No companion plugin is required. Additional procedures under `resources/` are readable references, not registered capabilities.

The [catalog](catalog/skill-set.json) lists discovered skills. [Third-party notices](THIRD_PARTY_NOTICES.md) preserve source provenance.

This legacy package distributes contracts and workflows; it registers no skills.
