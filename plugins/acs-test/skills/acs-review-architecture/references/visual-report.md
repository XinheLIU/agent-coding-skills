# Visual Report Contract

Last updated: 2026-09-17

This bundled copy makes `acs-review-architecture` portable. Generate compact HTML: a scorecard, one card per major finding, anchored evidence, a current/target visual for structural changes, one-sentence problem and fix, up to four wins, collapsed aspect detail, and one anchored top recommendation. Use inline SVG first; Mermaid is optional for graph-shaped relationships. Keep diagrams about 320–360px tall and preserve ordinary HTML labels as a CDN-failure fallback. Reference this file relatively; never require another skill or suite-level path.
