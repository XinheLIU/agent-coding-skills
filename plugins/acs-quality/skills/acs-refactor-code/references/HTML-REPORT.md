# HTML Report Format

Last updated: 2026-09-30

Use the local `visual-report.md` contract. A structural refactor report compares baseline and post-change structure, cites the same checks and environment, and makes the structural delta visible before listing deferred debt.

A refactor report is a one-off report: name it `refactor-<slug>-YYYY-MM-DD.html`, and give every structural change an `article.card` with Before/After panes. Run the validator named in the visual contract before handing it over.
