# HTML Report Format

Last updated: 2026-09-14

Use the local `visual-report.md` contract. The HTML companion mirrors the architecture review scorecard and major findings while keeping the Markdown report canonical.

Use one card per major cross-aspect or aspect finding. Structural findings receive a 320–360px current/target visual; score-only findings state why comparison is not applicable. Preserve aspect, confidence, severity, and file/line evidence. Use inline SVG first, Mermaid only for graph-shaped relationships, and collapsed evidence for long reviewer detail. End with one anchored top recommendation.
