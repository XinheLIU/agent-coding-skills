# Visual Report Contract

Last updated: 2026-09-14

Structural refactor reports use inline CSS and inline SVG as the source of truth. Show the current/target structure, removed shallow modules, new seams, moved ownership, and preservation evidence. Each structural delta has an adjacent takeaway and an anchored top recommendation; Mermaid is optional for graph-shaped relationships and ordinary HTML labels remain readable without scripts. Keep diagrams roughly 320–360px tall.
