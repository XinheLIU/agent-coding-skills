# Quality · Testing

Last updated: 2026-08-09

Ensuring code does what it claims through automated verification and test coverage analysis.

| Skill | Owns |
| --- | --- |
| `tdd` | Test-driven development workflow — write the failing test first, then make it pass |
| `analyze-test-gaps` | Audit existing test coverage; identify untested paths and missing edge cases |

`tdd` drives feature implementation. `analyze-test-gaps` is a review tool used after the fact or during QA.
