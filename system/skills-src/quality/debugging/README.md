# Quality · Debugging

Last updated: 2026-08-09

Diagnosing and resolving defects — from initial signal to root cause to fix. Used reactively when something breaks.

| Skill | Owns |
| --- | --- |
| `triage` | Classify an incoming bug report: severity, scope, reproduction steps, likely owner |
| `diagnosing-bugs` | Root-cause analysis — trace from symptom to cause through logs, state, and code |
| `resolving-merge-conflicts` | Resolve git merge conflicts with correct intent reconstruction |

The typical flow: `triage` to classify → `diagnosing-bugs` to find the cause → fix → `request-code-review` in `quality/review/`.
