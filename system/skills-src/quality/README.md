# Quality

Last updated: 2026-08-09

Ensuring correctness, clarity, and resilience across all phases of engineering. Three concerns that are not sequential — they run throughout delivery.

| Sub-phase | Concerns | Directory |
| --- | --- | --- |
| Testing | TDD workflow, test gap analysis | `testing/` |
| Review | Architecture review, code review, design review, refactoring | `review/` |
| Debugging | Diagnosis, triage, merge conflict resolution | `debugging/` |

Review skills span all artefacts (architecture, design docs, implementation gaps, code quality). The distinction from testing: review is a human or agent judgment pass; testing is automated verification.
