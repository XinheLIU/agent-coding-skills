# Quality · Review

Last updated: 2026-08-09

Reviewing and improving artefacts at every level — architecture decisions, design docs, implementation gaps, and code quality. Covers both the judgment pass (review) and the corrective action (refactor/simplify).

| Skill | Owns |
| --- | --- |
| `review-architecture` | Review system or module architecture against design goals and constraints |
| `review-design-doc` | Review a design document for completeness, clarity, and internal consistency |
| `review-implementation-gaps` | Identify gaps between what the design specifies and what the implementation delivers |
| `review-code-quality` | Review a change against this repo's documented coding standards |
| `request-code-review` | Pre-commit review: security scan, quality gates, and auto-fix |
| `refactor-code` | Restructure code through small, safe, measurable transformations that preserve behavior |
| `simplify-code` | Polish recently modified code for clarity and project-style consistency |

Review flows down: architecture → design doc → implementation gaps → code quality. Refactor and simplify act on the findings.
