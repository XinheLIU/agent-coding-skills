# Visual Report Contract

Last updated: 2026-09-14

Use inline CSS and inline SVG as the source of truth for architecture option reports. Each option card names the current/target states (ideal and feasible), shows trade-offs, includes an adjacent takeaway, and ends with one anchored top recommendation or selected decision. Mermaid is optional for graph-shaped relationships; ordinary HTML labels remain readable without it. Keep diagrams roughly 320–360px tall.
