# Craft · Meta

Last updated: 2026-08-09

Skills about working with the skill system itself — research, planning tools, and skill authoring. Used when improving or extending the engineering workflow, not when delivering product features.

| Skill | Owns |
| --- | --- |
| `research` | Deep research on a technical topic; synthesizes primary sources into a decision-ready summary |
| `grilling` | Stress-test a design or plan by generating adversarial questions |
| `draw-portfolio-dag` | Visualize a project portfolio as a dependency DAG for sequencing decisions |
| `writing-great-skills` | Guide for authoring high-quality agent skills in this system |
| `review-agent-instructions` | Review agent instruction files (CLAUDE.md, AGENTS.md, skill files) for quality |
