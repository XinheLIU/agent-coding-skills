# Workflows

Last updated: 2026-09-09

Workflows compose skills around the [shared memory protocol](../skills-src/craft/context/init-context/references/PROTOCOL.md). Skills provide focused behavior; workflows own sequencing, approval gates, and state transitions.

- [Ideas](ideas.md) — turn an uncertain concept into approved intent.
- [Feature delivery](feature-delivery.md) — move approved intent through specification, planning, tickets, implementation, and review.
- [Testing](testing.md) — choose seams, execute TDD, and audit test gaps.
- [Debugging](debugging.md) — build a red-capable feedback loop, diagnose, fix, and retain the regression test.

Shared [context coordination](context-coordination.md) owns resolution, runtime binding, scheduling, claims, shared writes, freshness, and retention. [Design](design.md) covers accepted intent; [Operations](../skills-src/operations/README.md) defines the release boundary.
